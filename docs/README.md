# Kubemoot documentation

This folder is the source of the Kubemoot documentation. Read it rendered at
**https://kubemoot.org/docs/**.

The pages are written for the documentation site, and most cross-page links use the
site's URL layout. Browsed here on GitHub, many of those links land one folder too high
and do not resolve. The rendered site has working navigation, search, and links, so start
there.

To fix or extend a page, edit the Markdown in this folder and open a pull request. The
contribution guide is at https://kubemoot.org/docs/community/contributing/.
